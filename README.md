# Free Fire - Inventário do Jogador

Este é um sistema de inventário para um jogo de sobrevivência inspirado no Free Fire. 
O programa permite ao jogador cadastrar, remover, listar e buscar itens em sua mochila virtual.

## Funcionalidades

- Adicionar item (nome, tipo e quantidade)
- Remover item pelo nome
- Listar todos os itens da mochila
- Buscar item pelo nome
- Sair do sistema

## Tecnologias

- Linguagem: C
- Compilador: GCC

## Como Compilar e Executar

No terminal (PowerShell) dentro da pasta do projeto:

```powershell
gcc free-fire.c -o free-fire.exe
.\free-fire.exe
